# CampusHub

Student library and campus store (front-end demo).

## Run in VS Code
1. File > Open Folder > choose this CampusHub folder.
2. Install the Live Server extension (Ctrl+Shift+X).
3. Right-click index.html > Open with Live Server.

## Use
1. Register the first account (it becomes the admin).
2. Log in. The admin adds books, notes and other items with buy and rent prices.
3. Students buy or rent items and see orders under My orders.

Data is saved in the browser (localStorage). A Spring Boot + MySQL backend can replace it later.
